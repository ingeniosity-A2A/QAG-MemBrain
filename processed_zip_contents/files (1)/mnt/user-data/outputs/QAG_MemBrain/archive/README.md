# /archive — Legacy References

Read-only copies of prior repositories for historical reference only.

## Rules
- No new code is added here
- No active QAG_MemBrain dependency points into this directory
- Reference only — for migration decisions and understanding prior design choices

## Contents
- `/legacy-references/` — Shallow clones or tarballs of AVA007, AvaPy, Ingeniosity, and related repos
- `migration-notes.md` — What was moved, what was discarded, and why

## Un-archiving policy
Legacy repos on GitHub are set to read-only (archived).
Un-archiving requires explicit written approval from the architecture lead.
A legacy repo must never become an active development target again.
