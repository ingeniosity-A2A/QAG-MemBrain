# Archived Legacy References

Read‑only copies of previous repositories (AVA007, AvaPy, etc.) for historical reference.

## Purpose
- Preserve old code and documentation without active development.
- Avoid accidental deletion of prior work.

## Rules
- No new code shall be added to `/archive`.
- No active dependencies from QAG_MemBrain core shall point to `/archive`.
- Reference only for migration or understanding past decisions.

## Contents
- `legacy-repos/` – Zipped or shallow‑cloned versions of old repositories.
- `migration-notes.md` – What was moved, what was discarded.
