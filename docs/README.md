# Documentation

This directory contains architecture documents, specifications, and developer guides.

## Subdirectories
- `/architecture` – High‑level system design, layer diagrams, data flow.
- `/specifications` – Detailed specs for JSONL schema, Tashi vertex format, GSAP timeline serialization, API contracts.

## Key Documents
- `REPOSITORY_CHARTER.md` – Governance and scope.
- `CONSUMPTION_API.md` – How surface packages interact with QAG_MemBrain.
- `MIGRATION_PLAN.md` – Steps to move from legacy repos.

## Usage
All documentation is written in Markdown. Keep diagrams as ASCII or Mermaid.
