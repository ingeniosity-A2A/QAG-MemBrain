# Cavern Room Correction & Dolby Atmos with Goose / QAG-MemBrain

## Overview

**Cavern** (cavern.sbence.hu) is a free, powerful room correction suite and Dolby Atmos decoder/renderer for Windows/macOS/Linux. It includes QuickEQ calibration, measurement processing, and high-end audio tools.

Ideal for audio enthusiasts and media production agents in QAG-MemBrain.

## Main Features

- Room analysis and correction filters
- Dolby Atmos support (decoder + renderer)
- QuickEQ automatic calibration
- File-based processing
- Integration with media players and DAWs

## Usage with Agents

Use Goose to orchestrate measurement -> calibration -> rendering pipelines.

## Example Prompts

- "Run a room measurement workflow using Cavern and generate correction filters."
- "Process this multi-channel audio file with Cavern for Dolby Atmos playback."
- "Automate QuickEQ calibration and apply the resulting filters to my listening setup."
