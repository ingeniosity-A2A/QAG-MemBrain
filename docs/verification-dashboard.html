🔗 Cross-Repo Contract Verification

❌ ObservationProposal Format Mismatch

The DUAL_CONSCIOUSNESS_CONTRACT.md defines a specific ObservationProposal interface. Neither QAG-MemBrain's TypeScript nor Ava007's Python implementation matches it.

Contract specifies: type: "observation_proposal" | source: "REV.IKE" | timestamp | content: { interpretation, pattern?, question?, ... } QAG TS actual: type: "observation" ❌ | source: "rev_ike_lens" ❌ | No timestamp ❌ | Uses "insight" instead of content.interpretation Ava007 Python actual: 14 fields (vs 6 in contract) | No type/source/timestamp fields | Uses "insight" + "philosophical_diagnosis" + "strategic_advice" + "tactical_directive"

⚠️ Ava007Adapter Import Path — Fragile

The adapter resolves Ava007 via Path(__file__).resolve().parents[4] / "Ava007". This requires both repos to be cloned as siblings. Works in dev, may break in production deployments.

✅ Authority Order — Enforced in Code

CANONICAL_AUTHORITY_ORDER = ["JSONL", "Tashi", "Neo4j", "GSAP", "Runtime"] is defined in replayContract.ts and validated at load time by governanceLoader.ts. Throws error if manifest doesn't match.
